## Getting Started

To create your own blog post:

1. Create a new file in the `_posts/` directory
2. Name it with the format `YYYY-MM-DD-title.md`
3. Add YAML frontmatter with `title`, `date`, and optional `categories`
4. Write your content in Markdown

That's it! Jekyll will automatically generate the post page and add it to the blog index.
